# 教学指引 · 上有政策（PolicyLab）

如何在课堂使用 **上有政策 / PolicyLab**，以及它为何而生。

本指引写给任课教师。[README](../README.md) 说明这个系统是什么、如何搭建；本文件说明这节课本身。

---

## 1. 设计：从后果中学习

多数学生难以直观体会一项政策为何「知易行难」——纸面设计良好的政策，落到执行层面却可能大幅走样。抽象的讲授很难落地，可观察的后果可以。政策模拟把这种落差变成一段安全、可重复的经历：学生做一步决策，十一項社会发展指标与一条「模糊度 × 冲突度」执行轨迹随之移动，因果不藏在最终揭示之后。

这个项目要回答的设计问题是：**当学生目睹「好政策未必落地」时，会发生什么？** 单一的「意图计分板」有一个隐藏缺陷——学生很快学会最优策略「永远选最稳妥、最模糊的选项组合」，从而收集到「理想结局」。但这恰恰不是政策课程要教的：真实世界里，执行取决于标准的清晰度与利益的协调，再好的设计也会在执行中打折。

因此，每一局同时携带两类信息：

| 维度 | 含义 | 更好意味着 |
|---|---|---|
| 意图效果（预期） | 设计者期望政策带来的影响 | 经本步 Matland 执行系数打折后，才计入「实际落地」指标 |
| 实际落地 | 意图效果 × 本步执行系数，钳制于 0–10 | 系数越高（行政性 1.0），越接近意图 |
| 模糊度 × 冲突度 | 由本局固定层面的基线叠加玩家选择，决定 Matland 落点 | 越接近「低模糊、低冲突」越能全额落地 |

模糊度与冲突度不是「质量」，而是「执行性格」的两个轴。把它们当作质量轴来读，正是学生最容易犯的错误——务必在课堂点明。

### 四个结果象限，与 Matland 的四种执行

依 Matland（1995）模糊—冲突二维模型，整体路径落于四象限之一；每个象限对应一种执行类型，并给出叙事解释：

**Matland 模糊—冲突矩阵（一眼看清四象限）**

| | 低模糊度（目标与手段清晰）<br>a &lt; 0.5 | 高模糊度（目标与手段含糊）<br>a ≥ 0.5 |
| :--- | :--- | :--- |
| **低冲突度**<br>（利益一致）<br>c &lt; 0.5 | **行政性执行** · 系数 1.0<br>标准清晰、利益一致，政策接近全额落地 | **试验性执行** · 系数 0.7<br>目标含糊但利益一致，边做边试，部分落地 |
| **高冲突度**<br>（利益对立）<br>c ≥ 0.5 | **政治性执行** · 系数 0.6<br>标准清晰但利益对立，需政治妥协，效果打折 | **象征性执行** · 系数 0.2<br>标准未定且立场对立，多流于口号，几乎不落地 |

上面这张 2×2 网格就是 Matland 模型的原貌：两轴交叉产生的四个格子，正是游戏结尾「四种结果」。下方把每个格子的执行性格与系数展开说明：

| 象限 | 模糊度 | 冲突度 | 执行系数 | 含义 |
|---|---|---|---|---|
| 行政性执行 | 低 | 低 | 1.0 | 标准清晰、利益一致，政策接近全额落地 |
| 政治性执行 | 低 | 高 | 0.6 | 标准清晰但利益对立，需政治妥协，效果打折 |
| 试验性执行 | 高 | 低 | 0.7 | 目标含糊但利益一致，边做边试，部分落地 |
| 象征性执行 | 高 | 高 | 0.2 | 标准未定且立场对立，多流于口号，几乎不落地 |

**开玩前值得先点出两个象限。**「行政性执行」与「象征性执行」同在模糊—冲突轴的两端——一个接近全额落地，一个几乎空转——游戏明确把「只追求稳妥」视为不足。另一个值得点出的是：同一难题由不同层面（宏观／中观／微观）着手，基线不同，政策命运根本不同；这正是混合政策周期理论（Vidovich 2007）想教、却最难让学生「感到」的东西。

（注：本系统把每步的 Matland 执行系数真正乘到设计意图上，再计入指标——「象征性执行」系数 0.2，意图效果被折损至几乎为零；「行政性执行」系数 1.0，意图全额落地。因此「纸面改善」与「现实落地」在每一个数字上都是分开的，可作为课堂讲清「知易行难」的抓手；一份象征性执行的真实样例见[示例复盘报告](examples/示例报告-网约车算法-象征性执行.md)。）

### 层面（宏观／中观／微观）如何接入机制

每局开局随机抽「场景 × 层面」组合，整局固定一个层面。层面不只是一个标签，它给模糊度／冲突度设一个基线，玩家的「推行方式」再在其上叠加增量：

| 层面 | 模糊度基线 | 冲突度基线 | 典型执行性格 |
|---|---|---|---|
| 宏观 · 中央政府 | 0.55 | 0.55 | 原则强、利益多元 → 偏向高模糊高冲突 |
| 中观 · 地方政府 | 0.45 | 0.50 | 承上启下翻译层，临近阈值 |
| 微观 · 企业层面 | 0.40 | 0.55 | 规则明确（低模糊）；与监管对立（高冲突） |

所以即使同一道题，在中央政府手里和在企业手里，也会走向不同象限——这是 L07「混合政策周期理论」的可玩化。

**「上有政策，下有对策」如何落在设定里。** 抽到中观或微观层面时，开场卡会先呈现一份上级来文（中观来自中央政府，微观来自监管部门），写明上级要求与留给下级的裁量空间；玩家此后每一步选择，都是在此既定框架内决定怎么落实、怎么变通——这就是「下有对策」。抽到宏观层面时没有上级来文，玩家自己就是政策的发起点。建议让同一小组用同一场景连玩两局（一局宏观、一局中观或微观），对照「制策」与「承接」两种处境；这比单讲政策传导更能让学生感到落差。上级来文写在 `data/scenarios.js` 的 `upperPolicy` 字段，可按课程需要改写。

## 2. 课程背景与学习目标

本系统为 **PUA6027 科技与创新政策**（香港教育大学）而写，亦可不作改动地用于其他科技政策类课程。

**课程要求学生同时把握的两根线索。** 一根是科技与创新：科研如何转化为产品、产业如何被新技术重塑、伦理与法律红线在哪里。另一根是政策过程：政策如何分类、如何在不同层面（宏观／中观／微观）递归、为何「知易行难」。

| 课程关切 | 系统让学生做的事 |
|---|---|
| 科技与创新的动力机制 | 指标简报中的「创新活力／产业竞争力／技术成熟度」随政策移动，按一下按钮就是在练习政策如何作用于产业 |
| 政策分类与工具 | 每个决策点的「推行方式」选项，本身就是一类政策工具（强制、试点、自律、协商） |
| 宏观—中观—微观三层治理 | 每局固定一个层面，层面基线框定政策的典型执行性格，使「层面」成为可比变量 |
| 伦理、法律与社会影响 | 「隐私安全／公共信任／社会公平」等维度独立成轴，让「合法但无人买账」「安全但社会不接受」成为不同计分，而非一个模糊警告 |
| 问责与执行落差 | 结尾的 Matland 复盘把结局对回学生真实走过的决策点，点出「哪一步把冲突推高了」 |
| 反思性写作 | 每局复盘报告本身即一份结构化草稿：为何落此象限、牺牲了什么、谁受影响、本可如何取舍 |

## 3. 课堂运行

### 课前

- 在课室浏览器打开已部署站点，确认可加载。本系统为静态站点：无后端、无构建、无登录、无需安装。
- 把 **指定场景链接** 发给学生可触达之处。在链接后追加 `?s=ride_hailing` 可固定场景，便于全班比较同一道题。
- 若设备少于学生数，按两人一组规划。系统本就支持同桌协作。
- 提醒学生导出本局复盘报告。后续讨论都依赖这份报告。

### 课堂节奏

**第一轮——个人，指定场景。** 10 至 15 分钟。学生玩到结局并导出报告。先个人很重要：可避免小组里由一人替两人决策。

**第二轮——小组，任意其他场景。** 5 至 10 分钟。换一个场景，让学生看到同一类困境换了一层皮。每局存于浏览器，换场景不丢上一局，学生可回看对照。

**报告分析——先小组、后全班。** 15 至 20 分钟。学生基于自己导出的报告讨论。教学真正发生在这里，游玩只是铺垫。

### 好用的问题

这些问题都来自系统自身的输出，答案在学生报告里，而非教师脑子里。

- **「哪一步让它变得不可避免？」** 复盘页把每个数字归因到具体决策点。因为一局之内毫无随机，存在真实答案，报告即证据。
- **「第 2 步真是主因，还是第 1 步就已累积？」** 让学生为归因辩护或反驳。这正是反思论文需要的习惯。
- **「你落在了哪个象限？」** 把四个象限写在黑板上。「行政性」与「象征性」同在两端却都被定义；「政治性」与「试验性」都是折中。争论哪种折中更差，就是真正的课程内容。
- **「这一步造成的损害，谁有能力补救？」** 每个选择都隐含了补救主体在政策设计、企业自律还是法律。多数学生默认答案是「法律」，通常并非如此。

### 若时间紧张

保留第一轮与报告分析，砍掉第二轮。单局完整报告已足够，报告承载讨论所需的全部内容。

### 若学生进度不一

较快的小组可导出后重玩同一场景作两局对照，或阅读未抵达结局的复盘——每份复盘自成一体，可充当未游玩局的范例。

## 4. 复盘报告

每局导出三种格式，均在浏览器内生成：

| 格式 | 用途 |
|---|---|
| **Markdown 示例** | 便于阅读、打印与提交。含场景简报、指标总账、每个决策点及其指标增减与解析、完整 Matland 复盘 |
| **Word（.docx）示例** | 同样内容转为文档，可直接提交 |
| **JSON 示例** | 完整决策轨迹与复盘作为数据，便于评分或进一步分析 |

三者共享同一结构：开头先列本局的**「上级来文（上有政策 / 下有对策）」**设定（宏观局则注明「政策发起点，无上级来文」），随后是结局象限，再分节复盘。导出文件分四节——一、政策执行结果（Matland 四象限）；二、决策轨迹（按决策点）；三、社会发展指标总账（开局 → 终局）；四、Matland 复盘。屏幕上结局页把结局象限单独成卡，其后分三节（一、决策轨迹；二、指标总账；三、Matland 复盘），对应导出文件的第二至四节。所以学生按节名指认时，无论看屏幕还是看导出文件，都能对上同一处内容。

报告是一局唯一的持久记录，值得每次都要求导出。它也是进入写作的桥：复盘已按「为何落此象限、牺牲了什么、谁承担代价、本可如何、反思」组织好，学生只需用自己的话重写。

一份真实样例见 [示例复盘报告](examples/示例报告-网约车算法-象征性执行.md)。

## 5. 需要向学生说明的两件事

**系统是确定性的，而这正是重点。** 一局之内没有任何骰子。相同选择永远产生相同结局，所以「在哪一步变得不可避免」有真实答案。整个产品里唯一的随机元素，是开局抽取你玩哪一局、哪一个层面——仅此一次。

**三种层面是三种不同的游戏。** 这值得大声讲，因为很容易误以为不然。宏观、中观、微观各有不同基线，同一道题在不同层面会走向不同象限。两种后果：

- **固定 `?s=` 固定场景，但层面仍随机。** 若你固定 `?s=ride_hailing`，全班玩同一道题；学生若自行换层面，仍在同一道题里用不同层面作答。要么在开课前说明「全班固定同一层面」，要么让他们随机抽。
- **重新平衡结果只需在各层面各调一遍，而非三套。** 若你改编场景，平衡工作按层面做即可。

## 6. 改编与扩展

引擎是通用的。每个场景是一个独立的 JSON 数据包，所以一个新主题就是新文件，而非新程序。这是对你自己课程最有用的扩展。

**编写场景工作坊。** 让学生借助 AI 助手，共同起草一个新政策难题场景——一个算法治理困境、一个科研伦理问题——然后讨论每个选项的模糊度／冲突度增量是否合理、意图效果是否贴切。*那场讨论本身就是课程*：一个某些选择无处可去的场景是坏故事，而工具会说出它。

[Vibe-coding 指南](vibe-coding-guide.md) 含一份完整的提示词，用于生成符合架构的场景数据包；架构（字段含义）已在 README 与 `data/scenarios.js` 顶部注释中说明。

## 7. 已知限制

| 限制 | 应对 |
|---|---|
| 场景与层面每页加载随机抽一次 | 用 `?s=<id>` 固定演示用场景；本版每局固定一个层面 |
| 反思依赖课堂引导 | 复盘支撑讨论但不替代它 |
| 当前为垂直切片，仅 3 场景 × 3 决策点 | 按相同结构追加场景与决策步即可，无需改动引擎 |
| 「行政性执行」需刻意协调，非默认 | 把它当标杆而非目标；「政治性／试验性执行」才是现实常态 |

**已落地（本次增强）：** 每步的 Matland 执行系数已真正乘到设计意图上，再计入指标。「象征性执行」（系数 0.2）一局里意图效果被折损至几乎为零，指标总账与开局一致；「行政性执行」（系数 1.0）则全额落地。这消除了旧版「纸面移动却叙事空转」的张力，并使「知易行难」在每一个数字上可见。详见[示例复盘报告](examples/示例报告-网约车算法-象征性执行.md)。
